# Gate 1F-A — Genome, not graph

Gate 1F-A asks whether DifferentMachine can inherit a **small shared developmental rule** instead of inheriting a graph.

The experiment deliberately erases the grown phenotype and keeps only a 10-float genome. The same rule is then asked to grow a new sparse receiver-local graph on unseen worlds, larger substrates, and after a hidden task-regime change.

This is an evo-devo / structural-plasticity mechanism receipt, **not** a novelty claim or a full architecture result.

## Why this gate exists

Gate 1E-A removed the explicit useful-pair teacher, but still had two major cheats:

1. every node was handed a fixed 12-candidate proposal scaffold;
2. eligibility was measured with an ordinary receiver query plus an edge ablation query plus a candidate perturbation query.

Gate 1F-A removes both from the instrument.

```text
small inherited genome
        |
        v
shared local developmental rule
        |
        +-- geometry creates encounters / candidates
        +-- ordinary activity updates local residue
        +-- ordinary transported signal leaves eligibility
        +-- delayed scalar reward stabilizes / weakens used edges
        |
        v
sparse grown phenotype
```

No useful-neighbor ids are stored in the genome. No proposal matrix exists in the phenotype. No counterfactual receiver traversal is needed to measure eligibility.

## Genome

The reference genome contains ten raw float64 values: **80 bytes**.

They decode to bounded coefficients controlling:

- distance preference;
- recent-activity similarity;
- optional phase similarity;
- growth bias;
- newborn edge strength;
- local strength decay;
- delayed credit learning rate;
- pruning threshold;
- activity-trace decay;
- activity-driven phase drift.

Every node uses the same rule.

The canonical genome is produced by a deterministic mutation-only genetic algorithm:

```text
evolution training size  N=48
training world seed      101
evolution seed           7
population               14
generations               9
genes                     10
```

Re-running:

```bash
python experiments/gate1f_genome_not_graph.py --evolve
```

reproduces the banked winner and fitness:

```text
fitness = 0.680796

raw genome =
[-0.31887550, +0.00685164, +0.69949635, -0.28542975,
 -1.14091092, -1.51895493, -0.69230545, +0.44838466,
 +1.39977894, +0.59710920]
```

The outer GA evaluates whole-lifetime task consequences. The lifetime machine itself does **not** run a GA.

## Candidate generation from geometry

Each world places nodes at constant density in a 2-D substrate. A fixed-radius spatial hash partitions the substrate.

When an addressed node attempts growth, it inspects only its own 3x3 spatial-cell neighborhood. Thus candidate availability is generated by position rather than a hand-prepared useful-neighbor list.

At fixed density and radius the expected local inspection count should remain roughly capacity-independent. The reference sweep tests this explicitly.

This is a computational geometry instrument, not a biological claim that dendrites perform spatial hashing.

## Eligibility as residue, not experiment

During an ordinary sparse receiver query, a value that actually crosses edge `i -> j` is already part of the additive receiver output.

The edge therefore leaves a tiny local eligibility record:

```text
(source=i, target=j, signed transported contribution)
```

No edge is ablated. No candidate is temporarily inserted and re-queried.

Eight task events later the environment supplies only:

```text
+1  earlier task decision was correct
-1  earlier task decision was wrong
```

That delayed scalar reward modulates only edges that actually carried the earlier signal. Weak touched edges can fall below a local pruning threshold and die. Geometry can later grow replacements.

So Gate 1F-A implements a much cheaper version of the Gate 1E idea:

> **ordinary participation leaves the credit residue.**

## Synthetic task

The substrate has two receivers. Each receiver sees a different smooth binary field over the same positions. A node's own observation is noisy (`mu=0.55`), so a single-node decision is only about 0.69--0.71 accurate.

A sparse query may visit at most six nodes through the grown graph and aggregate their observations.

After the first lifetime phase, both receiver tasks are replaced by independently generated smooth fields without resetting the graph or genome. Growth, pruning and reward-modulated eligibility must adapt the phenotype.

The task is intentionally favorable to local geometry. That is a limitation, not hidden evidence.

## Full local receipt

Command:

```bash
python experiments/gate1f_genome_not_graph.py --full
```

The genome was evolved only at `N=48`. The full transfer sweep uses unseen seeds `41,42,43` and erases the phenotype before every run.

```text
N    initial  learned-old  shift0  recovered  queryW  candidateW  edges/node  phenotypeKB
64     .714      .781       .719      .780      7.53      22.24       1.141       10.0
128    .684      .785       .715      .784      6.27      25.18       1.040       20.0
256    .704      .783       .746      .773      7.17      27.07       1.114       40.0
512    .707      .791       .736      .783      7.11      28.90       1.110       80.0
```

Important observations:

- represented capacity grows from `64 -> 512` while the inherited genome remains 80 bytes;
- the grown phenotype is linear-memory, as expected;
- mean sparse-query work stays about `6--8` logical operations;
- geometry candidate discovery rises only from about `22 -> 29` inspections/event over the 8x capacity sweep;
- the phenotype remains very sparse at roughly `1.0--1.14` active directed edges per node despite degree 4 capacity;
- after an unseen task-regime change, lifetime development again improves the receiver over the immediate post-switch state.

The fixed degree and six-node query budget make bounded inference work possible by construction. The nontrivial part of this gate is that **candidate discovery and phenotype re-growth also stay local in this constant-density substrate**.

## Controls

At `N=128`, three unseen seeds:

```text
condition                     learned-old   recovered
full developmental genome        .785         .784
no delayed flow credit           .758         .720
no growth                        .726         .732
static phase, matched offset     .773         .765
```

The no-growth control stays close to the noisy single-node baseline.

Growth without delayed flow credit helps the initial regime somewhat, because geometry and local state already contain useful structure, but it adapts poorly after the hidden switch.

The phase control holds the phase term's constant offset fixed while removing dynamical phase differences. It degrades performance only modestly. Therefore Gate 1F-A does **not** support a claim that oscillation is essential. Phase remains an optional coordinate that happened to receive nonzero evolutionary weight in this toy.

## Genome versus phenotype transfer

This is the most important control in the gate.

A phenotype is first grown at `N=64` in the evolutionary training-world family. Then its adjacency/strength matrix is copied by node index into unseen `N=64` worlds without development.

Compare:

```text
erase graph + regrow from same genome   .781
replay inherited grown graph            .647
```

The learned graph itself does not transfer well. The constant-size rule that rebuilds a graph transfers substantially better.

Narrow interpretation:

> **What transferred in this toy was more useful as a developmental rule than as the previously acquired topology.**

This is exactly the distinction Gate 1F was designed to expose.

## Birth and death in this gate

Gate 1F-A has **edge birth and edge death**:

```text
geometry encounter -> edge birth
normal use -> eligibility
reward + residue -> stabilization / weakening
weak touched edge -> pruning / death
new encounter -> replacement growth
```

It does **not** yet have node/cell birth, differentiation, resource competition, or node death. Those should not be added until the edge-level developmental rule survives stronger tasks and real-stream controls.

## Prior-art guardrail

Do not claim invention of:

```text
genetic algorithms / neuroevolution
NEAT-style evolving topology
indirect / developmental encodings
HyperNEAT-like geometric generation
neural developmental programs
structural plasticity
reward-modulated plasticity / three-factor rules
activity-dependent pruning / growth
evolution of local learning rules
```

The possible DifferentMachine contribution remains the measured combination:

```text
constant-size inherited local rule
+ geometry/event-generated candidacy
+ persistent local state
+ bounded structural growth/pruning
+ receiver-relative sparse query frontier
+ normal-flow eligibility
+ delayed task consequence
```

with the specific systems question:

> **Can represented capacity and acquired structure grow much faster than the amount of machine that must wake, search, and adapt for each event?**

Gate 1F-A is only a synthetic mechanism receipt on that path.

## What remains cheated / unresolved

1. **Smooth spatial task.** Useful relations are deliberately correlated with physical proximity.
2. **One evolutionary training world.** The canonical GA optimizes on `N=48`, seed `101`; robust evolution across world distributions is not yet demonstrated.
3. **Fixed node set.** Edges grow/die, nodes do not.
4. **Fixed degree and query budget.** These bound inference by design.
5. **Python reference implementation.** No wall-clock/cache/memory-traffic claim.
6. **No strong retrieval controls yet.** HNSW/ANN, sparse tables, generic learned routers, event-RNN/delta baselines and MoE-style conditional computation remain mandatory.
7. **No real stream.** Candidate geometry is synthetic rather than coming from webcam/event vision or another naturally sparse substrate.

## Next gate

Do **not** add more biology first.

The next useful question is whether this same rule idea survives when geometry is not constructed to match the task:

> **Can an evolved shared local rule create and revise useful sparse structure from a real event stream, while local candidate discovery, update cost and receiver query work remain bounded as stored capacity grows?**

That is where `NeuromorphicDVSplusEMDfield` becomes the natural next substrate. Image/event coordinates supply real geometry; the comparison can include exhaustive template matching and ANN/HNSW rather than another synthetic graph-only control.
